# 왼팔 폭탄 투척

`PlayerAC.controller`의 `Bomb Left Arm` Override 레이어는 왼팔·왼손만 마스크한다. Humanoid 근육 키프레임 클립 `Player_BombLeftArm.anim`을 사용한다. 기본 Empty 상태는 애니메이션을 덮지 않고, `ThrowBomb` 트리거로 0.7초 투척 모션을 재생한 뒤 돌아간다. 오른팔은 기존 총을 잡는 애니메이션을 따른다.

`PlayerBombFire`는 G 키를 누르는 동안 충전하고 놓으면 투척한다. 기본값은 최소 힘 5, 최대 힘 20, 최대 충전 1.5초다. 최대 충전 이후에는 힘이 증가하지 않는다. 놓은 순간의 카메라 방향과 충전값을 저장하고 0.22초 뒤 기존 FirePoint에서 풀링된 폭탄을 발사한다. 폭탄 수는 실제 발사 시 감소한다. 전체 투척 시간 0.78초 동안 연속 투척과 폭탄 재장전을 막는다.

발사 위치는 기존 FirePoint에서 플레이어 기준 왼쪽으로 0.35m 이동한다. `_leftThrowOffset`으로 조정할 수 있다. 포커스 상실·비활성화·메뉴 진입 시 충전을 취소한다. B 재장전은 기존 방식이다. `_releaseDelay`와 `_throwDuration`은 클립의 발사 시점과 길이에 맞춘 값이므로 모션 변경 시 함께 조정한다.

## 사용자 Play 확인

Play는 실행하지 않았다. MCP로 클립의 Humanoid 채널, 마스크 범위, Animator 트리거와 씬의 폭탄 참조 및 충전 설정을 읽어 확인했다.

1. G 키를 짧게 누르고 놓은 경우와 1.5초 이상 누른 경우의 투척 거리를 같은 위치·시선 각도에서 비교한다.
2. 걷거나 달리면서 던져도 왼팔에만 투척 모션이 표시되고 오른손은 총을 잡고 있는지 확인한다.
3. 팔을 앞으로 뻗을 때 발사되는지, 투척 후 원래 자세로 돌아오는지 확인한다.
4. 충전 중 B로 취소하거나 창 포커스를 잃은 뒤 돌아왔을 때 의도치 않게 투척되지 않는지 확인한다.

새 모션의 자연스러움과 1인칭 화면에서의 가시성은 실제 카메라 구도에서 확인해야 한다.
