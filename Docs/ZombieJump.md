# 좀비 NavMesh 점프 추적

기존 ZombieJump, NavMeshAgent, 구워진 NavMesh를 사용하는 추적 보완이다. 씬, NavMesh 데이터, 미니맵은 이번 작업에서 수정하지 않았다. 컴파일 및 Play 검증은 실행하지 않았으며 아래 항목을 Unity에서 직접 확인한다.

## 동작

- 탐지 후에는 `Keep Chasing Player`가 켜져 있으면 생성 위치에서 멀어져도 계속 추적한다. 끄면 기존 Comeback Distance 제한으로 복귀한다.
- 목적지는 플레이어의 몸 중심이 아닌 콜라이더의 발 위치로 계산한다. 플레이어가 공중에 떠서 발 주변에 NavMesh가 없으면 마지막 지상 경로를 유지하고, 착지한 위치를 다시 추적한다.
- NavMeshLink에 도착하면 링크를 보존한 채 포물선으로 이동하고 착지 때 완료 처리한다. 추적뿐 아니라 순찰·배회·복귀에서도 링크를 넘는다.
- 링크 없는 발판은 높이 차가 있거나 걷는 경로가 끊겼을 때 탐색한다. 착지 후 플레이어의 발판까지 연결되는 NavMesh와 점프 궤적의 장애물 검사를 통과해야 한다. 범위 밖이면 NavMesh 경로를 따라 계속 접근한다.
- 착지 위치에 Agent Base Offset을 더해 모델 발이 발판 아래로 묻히지 않게 한다. 착지 후 최신 플레이어 위치로 다시 경로를 요청한다.
- 공중 피격 시 점프를 마친 뒤 피격 상태를 처리한다. 사망 시 점프를 취소하고 풀로 반환하며, 재사용 시 이동 설정과 점프 대기 시간을 초기화한다.

## 프리팹 설정

`Assets/03.Prefabs/Monster/Zombie.prefab`에서 설정한다.

| 컴포넌트 / 필드 | 현재 값 | 의미 |
| --- | --- | --- |
| Zombie / Keep Chasing Player | 켜짐 | 탐지 후 거리 제한 없이 추적 |
| ZombieJump / Allow Unlinked Jump | 켜짐 | 링크 없는 가까운 발판도 탐색 |
| Min / Max Jump Distance | 1.5 / 4.5 | 링크 없는 점프의 수평 거리 범위(m) |
| Min Jump Up | 0.8 | 걷는 경로가 있을 때도 점프를 고려할 높이 차(m) |
| Max Jump Up / Down | 1.5 / 5 | 링크 없는 점프의 최대 상승 / 하강 높이(m) |
| Jump Height / Duration | 1.5 / 0.7 | 시작·끝을 잇는 선 위 추가 포물선 높이(m) / 시간(초) |
| Jump Cooldown | 1.5 | 연속 점프 사이 대기 시간(초) |
| Obstacle Mask | Default | 벽·바닥·천장의 물리 레이어 |
| NavMeshAgent / Base Offset | 1 | 발 표면에서 루트까지 높이(m) |

지상에서 위층으로 바로 뛰어오르지 않도록 자동 점프의 최대 상승 높이를 3.5m에서 1.5m로 줄였다. 런타임에 컴포넌트를 추가하는 경우도 같은 제한을 사용한다. 높이 차가 1.5m를 넘으면 자동 점프하지 않고 기존 NavMesh 이동을 이어가며, 경사로를 올라 높이 차가 줄어든 뒤에는 짧은 점프를 할 수 있다. 점프 궤적의 추가 높이, 거리, 시간 및 하강 제한은 유지했다. 별도로 배치한 NavMeshLink는 수평 거리/높이 제한을 적용하지 않으며 궤적 충돌 검사는 적용한다. 위/아래 방향 이동은 링크의 방향 설정을 따른다.

착지할 발판에 좀비 Agent Type의 NavMesh가 있어야 한다. 벽이나 천장 때문에 궤적을 만들 수 없으면 점프하지 않는다. 발판이 너무 멀거나 중간 발판을 여러 번 거쳐야 하는 구간은 NavMeshLink로 경로를 연결한다. 자동 탐색은 주변 착지 후보 탐색이며 전체 맵의 다단계 점프 경로를 생성하지 않는다. 다른 레이어에 지형을 추가하면 Obstacle Mask에도 해당 레이어를 포함한다. 장애물 검사는 점프 시작 전의 지형 기준이다.

## 직접 확인할 순서

1. Unity에서 스크립트 컴파일 후 Console 오류를 확인한다.
2. GameScene을 Play하고 좀비에게 접근해 추적 상태를 만든다. 좀비보다 1.5m 넘게 높은 2층에 서서 지상에서 바로 뛰어오르지 않는지 확인한다. 경사로를 따라 접근해 높이 차가 1.5m 이내로 줄면 짧은 점프와 착지가 가능한지 확인한다.
3. 착지 직후 플레이어를 다른 위치로 이동한다. 좀비가 다시 경로를 계산해 접근하고 공격하는지 확인한다.
4. 아래 발판으로 내려가거나 연결된 다음 발판으로 이동한다. 반복 추적과 점프 대기 시간을 확인한다. 링크가 있는 구간은 순간이동 없이 포물선으로 넘어야 한다.
5. 벽·천장이 궤적을 막는 곳에서는 관통 점프하지 않는지 확인한다. 점프하지 않는 경우 먼저 거리·높이 제한, 발판의 NavMesh, 링크 방향을 확인한다.
6. 점프 중 좀비를 처치한 뒤 재생성한다. 공중에서 이동이 계속되지 않고, 재사용된 좀비가 정상 이동·점프하는지 확인한다.

## API 근거

- [Unity ResetPath](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AI.NavMeshAgent.ResetPath.html): 링크 위에서 호출하면 링크를 즉시 완료하므로 점프 시작 시 호출하지 않는다.
- [Unity CompleteOffMeshLink](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AI.NavMeshAgent.CompleteOffMeshLink.html): 수동 포물선 이동과 Base Offset을 포함한 끝점 계산을 참고했다.
